CampusPulse RELAY: data use

This is a hackathon demonstration. Public AI uses isolated temporary visitor workspaces without registration. Only upload permitted non-sensitive material. A server-side Gemini key is shared under bounded fair quotas. Free Gemini processing requires the displayed eligibility and data-processing confirmation; unpaid inputs may be used by Google for improvement and human review.

Documents, extracted quotations, history, plans and reported progress belong to the visitor's capability session. Hosting restart or redeploy can reset this temporary storage. Export a Workspace Passport and keep it private. Source content is never application authority.

Google Calendar connection is separate and voluntary. OAuth state and PKCE bind consent to the visitor's workspace. Refresh tokens are encrypted on the server. The default scope only supports secondary calendars created by this application; it cannot read existing personal calendars. Existing-calendar scopes require separate consent. Private Calendar event payloads and mutation tools are not sent to unpaid Gemini. Exact study writes always need a separate preview and explicit approval.

Disconnect removes the local token and attempts Google revocation. It preserves existing Calendar events; use reviewed guarded undo before disconnecting if desired. You can independently remove access in your Google account connections. Google consent, publishing eligibility and actual Calendar write/read-back acceptance may remain pending; the app reports those limitations.

Reset deletes the selected temporary workspace. Shared synthetic example data are labeled. No coursework is submitted, no messages are sent, and no grades are predicted. Project and issue contact: public source repository. Do not post documents or credentials in public issues.
