# Independent judge quickstart

Open **https://campuspulse-relay-demo.onrender.com** → **Enter public demo**. This is a free-hosted illustrative frontend + Python backend. Required managed GCP/Gemini/live Calendar acceptance remains blocked. Two-hour visitor sessions can reset earlier on hosting restart/redeploy; use permitted sample data. Local Windows uses the same UI with its localhost gateway.

1. On the prepared Windows machine, run `scripts/dev.ps1`, then open `http://127.0.0.1:8000` or launch the installed CampusPulse RELAY executable on D:.
2. Enter **Explore illustrative workspace**. The disclosure explains that course material and Calendar are illustrative; dedicated GitHub reads are real.
3. Open **Evidence**. Compare the original PDF's Thursday deadline with the revised source's Wednesday deadline. Open each page/ref. Choose a deadline explicitly.
4. Click **Repair my week**. Inspect the real solver status, 540-minute allocation and zero buffer. Open a study block for its cited rubric/next action.
5. In **Recovery**, choose **Lose Wednesday afternoon**. At least 120 minutes remain unscheduled. The baseline and calendar are untouched. Return to baseline.
6. Review the exact action preview, target, version/digest and freshness. Approve the **illustrative local actions** only. In Activity, inspect read-back outcomes and guarded undo. These are not Google Calendar writes.
7. Import an unseen text PDF/Markdown/TXT source (or ICS). Explicit ISO deadlines and effort/checklist fields are extracted conservatively. Ambiguous/missing values remain unknown and can be supplied explicitly. A poem creates no invented assignment.
8. In **Connections**, fetch the real `coursework.md` from the dedicated repository. Enable server polling if desired. Current live source revisions may differ from the fixed golden fixture; inspect new conflicts rather than silently accepting the newest date.
9. Inspect the execution journal and actual durations. Ask the assistant an unscripted question: without a managed resource, it returns the honest connection error. No scripted Gemini answer is substituted.

After GCP access is completed, repeat from a clean authenticated session with the actual returned web URL, verify the managed resource on the real path, select an authorized calendar, approve real changes and open external event links. Isolated judge access must be tested before sharing it; no shared password is provided.

## New unscripted route in 0.2.0

Choose **Judge challenge** in the sidebar. Import a permitted text brief in Evidence. Structured fields can use `Assignment:`, `Course:`, `Term:`, stable `Assignment ID:`, `Due:` with an ISO offset, `Effort:` and checklist lines. Missing course/term stays a separate draft: explicitly link it to a known assignment or create a course/term/key mapping. A similar title alone is never enough. Repeated semesters should have different terms. Exact source quotations remain unchanged in all UI languages.

After resolving conflicts, repair the week. Minimal Rescue compares only availability additions you offer. For the October 19 fixture, remove Wednesday and offer Tuesday 16–17 and Friday 17–18 (+05:00). Inspect the 120-minute total and 60-minute pre-lab shortages; Friday alone cannot solve it. Choose an option to re-read actual busy state; review and approve a fresh **illustrative** preview in Recovery. Live mode will require real Calendar consent and the same approval/read-back boundary.

For Submission Preflight, select the assignment and your draft. Explicit requirements can include `Filename: report-*.md`, `Format: md,pdf`, `Sections: Method;Results`, `Words: 100-1000`, `Pages: 1-3` (measurable only for PDF), and `Required files: report.pdf;data.csv` (declared inventory only). Structural presence is not semantic correctness. A filename exception needs review; screenshots, experimental validity and grading are never inferred from presence alone. Missing work can become a separate recovery scenario with a student-supplied effort assumption.

The Challenge evidence panel and Activity show own-source versions, useful tool observations, proposed plan changes and local-adapter read-back. No shared judge password, public admin/fault-injection controls or unrestricted code execution is exposed. Public manual GitHub refresh is real and may reuse an observation for five minutes; original commit/fetch time remains visible. Durable cloud autonomy is pending.
