Обновление и автоматические проверки не заменяют согласие владельца и физические действия Windows. Управление Windows после Escape не возобновляется.

## Calendar

OAuth client, API и Production уже настроены. Если прежний сеанс ещё connected=true, не подключайте Google повторно. После истечения/перезапуска временного пространства нужен новый поток только в том же браузере: Подключения → Учебный календарь → Подключить Google. Используйте свой аккаунт.

Восстановите ранее созданный приложением календарь по его действительному ID и выберите его кнопку. При404 проверьте ID и аккаунт; не создавайте дубликат вслепую. Для нового независимого проверяющего нужен его собственный отдельный app-created календарь.

В этом же пространстве импортируйте fixtures/calendar-readback-check.md и подтвердите одно задание. Выберите Asia/Almaty, даты2026-10-21–2026-10-21,18:00–18:30,среду; сохраните контекст и сформируйте план. Откройте точный live-предпросмотр: свой ID, ровно одна create-операция,21октября18:00–18:30. Только владелец может одобрить эту реальную запись после проверки.

После записи: verified-квитанция, свежее совпадающее чтение и ровно одно событие в Google. Отдельно проверьте повтор ТОГО ЖЕ одобренного запроса без дублей. Повтор чтения не заменяет повтор записи. Отмена теста требует отдельного решения владельца; проверьте удаление только его неизменённого тестового события. Отключение и подтверждение отзыва Google проверяются отдельно; отключение не удаляет события.

## Windows

Скачайте последний установщик и Install-D.cmd с GitHub Releases, поместите оба на D:. Закройте RELAY вручную и запустите Install-D.cmd. Владелец локального проекта также может выполнить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\projects\CampusPulseRELAY\scripts\install_release_native.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\projects\CampusPulseRELAY\scripts\recheck_release_native.ps1"
```

Скрипты берут текущую версию из package.json и проверяют установку именно на D:. Исходные профили сохраняются; проверка открывает отдельный профиль. Не удаляйте старую C: копию до успешной проверки D:.

Запишите отдельно: настоящий Open picker появился → Cancel; затем импорт public/samples/11-continued-brief.pdf успешен; настоящий Save picker сохранил Passport на D:; импорт как новой копии и повторное открытие сохранили источники/прогресс; уведомление действительно видно; click возвращает фокус приложению. Native Open/Save остаются на языке Windows, календарь внутри приложения — на EN/RU/KZ.

Не присылайте ключи, cookies, callback-адреса или approval digest. Сообщайте безопасный код ошибки и конкретный неуспешный этап.
