## Calendar: использовать существующий календарь

Старая область вернула AUTH_REQUIRED: её временный сеанс истёк. OAuth client, API Enable и Production уже настроены. Владелец уже повторно подключил Google к0.5.1: connected=true. Поэтому шаг2сейчас пропустите. Старый ID сначала вернул404, затем владелец успешно восстановил существующий календарь. Сейчас нажмите его кнопку в списке, затем переходите кшагу4; не создавайте дубликат.

1. В своём работающем браузере откройте https://campuspulse-relay-demo.onrender.com/ → «Свои документы». Если есть сохранённый Passport, импортируйте его ДО подключения Google: новая копия не переносит разрешения.
2. «Подключения» → «Учебный календарь» → «Подключить Google в системном браузере». Начните и завершите поток в одном браузере/профиле. Только владелец добровольно подтверждает app-created calendars. Не переносите OAuth/callback-ссылку.
3. После «Google подключён» откройте «Подключить ранее созданный календарь приложения». Введите ID своего CampusPulse RELAY Study → «Проверить существующий календарь» → выберите возвращённый календарь. ID: Google Calendar → настройки именно этого календаря → «Интеграция календаря» → «Идентификатор календаря». У владельца проекта прежний ID также сохранён только на D: в .local/calendar-acceptance/owner-target.json. Другой проверяющий использует свой календарь.
4. В этом браузере /api/connections/status должен вернуть configured/connected/calendar_live=true. Это ещё не проверка события.
5. Импортируйте fixtures/calendar-readback-check.md, проверьте и подтвердите одно тестовое задание. Период 21.10.2026–21.10.2026, 18:00–18:30, Asia/Almaty, среда разрешена. Дату сдачи в источнике не меняйте.
6. План → предпросмотр Calendar: режим live, свой ID, ровно ОДНА create-операция 21 октября 18:00–18:30. При расхождении ничего не одобряйте. Сообщите безопасное описание цели/времени/числа операций, без digest или approval JSON.
7. Владелец отдельно одобряет реальную запись. Нужны квитанция verified, «Проверить снова» с совпавшим чтением и одно событие по ссылке Google. Повторное чтение не доказывает идемпотентный повтор записи: безопасный повтор ТОГО ЖЕ одобренного запроса фиксируется отдельно, без нового плана/новых разрешений. Пока он не подтверждён.
8. Отмена — отдельное добровольное действие для неизменённых событий этой квитанции, затем проверка исчезновения именно тестового события. Отключение Calendar не удаляет события; подтверждение отзыва Google проверяется отдельно.

Реальные запись/read-back/повтор/отмена/отзыв остаются pending до наблюдения. Не присылайте токены, callback или полный /api/state.

## Windows: ручная проверка

Escape остановил управление Windows; автоматизация не возобновляется. Новые сборки не устанавливаются автоматически. Исходный профиль с 45/95 сохранён.

Обнаружен и исправлен дефект установщика: ранний выбор D: перезаписывался стандартной логикой electron-builder. Поэтому прежняя 0.5.1 попала на C:, а проверочный скрипт видел старую 0.5.0 на D:. Исправленный установщик использует собственный NSIS-сценарий с обязательным точным путём D:, без копирования установщика в LocalAppData. Успешная сборка и проверки кода не заменяют ручную установку.

Закройте RELAY вручную и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\projects\CampusPulseRELAY\scripts\install_release_native.ps1"
```

Установщик должен показать D:\projects\CampusPulseRELAY\installed\CampusPulse RELAY; завершите его. Скрипт проверит версию именно там. Затем:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\projects\CampusPulseRELAY\scripts\recheck_release_native.ps1"
```

Откроется отдельный профиль на D:. Исходный профиль с 45/95 не меняется. Пока новая D: установка не проверена, ошибочную копию на C: не удаляйте. После успешной проверки её можно удалить вручную через «Установленные приложения»: старую запись CampusPulse RELAY 0.5.1, не новую CampusPulse RELAY (D:). Сначала проверьте путь старого uninstaller в %LOCALAPPDATA%\Programs\CampusPulse RELAY. Не выбирайте удаление пользовательских данных и не удаляйте папки профилей. Автоматическое удаление C: не выполнялось.
